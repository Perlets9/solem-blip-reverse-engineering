## 2. The complete FREQ_TYPE table

| `FREQ_TYPE` (byte 4) | MySolem UI label | DOW_BITMAP role | PERIOD role | DAYS_TO_NEXT role |
|---|---|---|---|---|
| `0x00` | **Daily** (if DOW=`0x7f`) or **Custom** (otherwise) | Selected days | ignored | ignored |
| `0x01` | **Even days** | ignored | ignored | (today is even? 0 : 1) |
| `0x02` | **Odd days** *(Exclude 31st OFF)* | ignored | ignored | similar |
| `0x03` | **Odd days** *(Exclude 31st ON)* | ignored | ignored | similar |
| `0x04` | **Interval / Every N days / Weekly** | ignored | days between firings (2..30+) | days until first firing |

**MySolem UI label resolution** when reading back `FREQ_TYPE=0x04`:
- `PERIOD=2` → "Every 2 days"
- `PERIOD=3` → "Every 3 days"
- `PERIOD=7` → "Weekly"
- any other → "Interval" (with period shown separately)

The "Exclude 31st" toggle ONLY exists for Odd-days mode and is encoded as
a separate top-level frequency code (`0x02` vs `0x03`), not as a bit flag.

## 3. DOW_BITMAP — bit order CONFIRMED

Program C Custom mode in save batch 1 had `DOW_BITMAP = 0x6b`, and the
MySolem screenshot showed selection "Sunday, Monday, Tuesday, Thursday,
Saturday".

`0x6b` = `0b01101011`:

| Bit | Day | Set? | UI selected? | Match |
|---|---|---|---|---|
| 0 | Monday | ✓ | ✓ | ✓ |
| 1 | Tuesday | ✓ | ✓ | ✓ |
| 2 | Wednesday | ✗ | ✗ | ✓ |
| 3 | Thursday | ✓ | ✓ | ✓ |
| 4 | Friday | ✗ | ✗ | ✓ |
| 5 | Saturday | ✓ | ✓ | ✓ |
| 6 | Sunday | ✓ | ✓ | ✓ |
| 7 | (reserved) | — | — | — |

**Bit order**: `bit 0 = Monday, bit 6 = Sunday` (ISO-like, Monday-first).
`0x7f` (all bits 0–6 set) = all 7 days enabled.

## 4. Final consolidated flags-row layout

```
[?:3] [BUDGET] [FREQ_TYPE] [DOW_BITMAP] [PERIOD] [DAYS_TO_NEXT] [DAY] [MONTH] [YEAR:BE16]
  0     3         4            5            6           7            8       9      10..11
```

All fields decoded:

| Byte(s) | Field | Range / values | Notes |
|---|---|---|---|
| 0–2 | reserved | `00 00 00` | Always zero in captures |
| 3 | `BUDGET` | 0..200 (`0x00..0xC8`) | Water budget % |
| **4** | **`FREQ_TYPE`** | 0..4 | See §2 |
| 5 | `DOW_BITMAP` | bits 0..6, bit 0 = Mon | Used only when `FREQ_TYPE=0x00` |
| 6 | `PERIOD` | 2..30+ (uint8) | Used only when `FREQ_TYPE=0x04` |
| 7 | `DAYS_TO_NEXT` | 0..N (uint8) | Days from save day until first firing |
| 8 | `DAY` | 1..31 | Save day |
| 9 | `MONTH` | 1..12 | Save month |
| 10–11 | `YEAR:BE16` | e.g. `0x07ea` = 2026 | Save year |
